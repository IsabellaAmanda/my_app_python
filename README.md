# my_app_python

Aplicación en **PyQt5** creada como práctica de Programación Orientada a Objetos.

### 📝 Descripción
Repositorio de prácticas de Python que incluye:
* **Lógica de programación:** Bucles, condicionales y estructuras de datos.
* **POO:** Clases, herencia y polimorfismo.
* **Interfaces Gráficas:** Desarrollo con PyQt5.
